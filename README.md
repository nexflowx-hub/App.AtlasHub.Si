## Purpose

`app.atlashub.si` is the authenticated product surface of the AtlasHub ecosystem.

Planned capability domains:

- **Chat & Intelligence** — multimodal conversational workspace
- **Agents** — specialized and project-bound intelligent agents
- **Projects** — persistent project context, files and execution
- **Knowledge** — organizational and personal knowledge layers
- **Automation** — workflows, scheduled and event-driven execution
- **Research** — structured discovery and synthesis
- **Developer** — coding and technical execution surfaces
- **Teams** — collaborative workspaces, permissions and governance

## Ecosystem position

- `atlashub.si` — public gateway
- `app.atlashub.si` — authenticated intelligence workspace
- `academy.atlashub.si` — learning
- `editions.atlashub.si` — publishing

## Development workflow

1. Build and validate in `nexflowx-hub/App.AtlasHub.Si`.
2. Promote reviewed releases to `atlashub-digital/App.AtlasHub.Si`.
