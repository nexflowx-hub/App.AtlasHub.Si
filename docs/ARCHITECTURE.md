# App.AtlasHub.SI — Architecture Baseline

## Role

Authenticated intelligent workspace for the AtlasHub ecosystem.

## Initial domains

- identity and workspace shell;
- chat and multimodal interaction;
- agents and agent registry;
- project context;
- knowledge and memory;
- automation;
- research;
- developer tooling;
- teams and permissions.

The V1 repository is intentionally a shell. Product capabilities should be introduced as bounded modules rather than a monolithic assistant.
